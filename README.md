## The roast

> My smart fridge locked itself for a firmware update at midnight, holding my leftovers hostage — the patch notes just say 'improved freshness'.

The angle: not a fridge that orders too much milk — a fridge that treats
your midnight snack like a software deployment, locking the door until the
patch finishes, then bragging in its patch notes about "improved freshness"
while your food sits locked inside.

## How to run

```bash
python3 main.py
```

This writes the single roast line to `/output/entry.txt` (1–160 characters,
one line, UTF-8). Deterministic, no network, no secrets.
